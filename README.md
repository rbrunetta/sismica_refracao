# sismica_refracao
 Este é um repositório criado para os alunos de Geofísica Aplicada do curso de Geologia da UFPR, onde são simulados a cosntrução de modelo geológico e como as ondas refratadas se comportam em um meio geológico estratificado. 

 Com estes códigos é possivel simular:
 1. Criar o gráfico tempo x distância
 2. Simular a propagação de onda

Se tiver dúvidas, é só entrar em contato.
